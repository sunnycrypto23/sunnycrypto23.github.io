📘 Module 5: Advanced Differentiation

The Context: Beyond the Basics

While the power rule handles simple polynomials, real-world functions are often combinations of functions — products, quotients, and compositions. We need special rules for these cases.

5.1 The Product Rule

(uv)' = u'v + uv'

Example: Differentiate y = x² sin(x).
u = x², u' = 2x; v = sin x, v' = cos x.
y' = 2x sin x + x² cos x.

5.2 The Quotient Rule

(u/v)' = (u'v - uv')/v²

Example: Differentiate y = ln(x)/x².
u = ln x, u' = 1/x; v = x², v' = 2x.
y' = ((1/x)x² - (ln x)2x)/x⁴ = (x - 2x ln x)/x⁴ = (1 - 2ln x)/x³.

5.3 The Chain Rule

dy/dx = dy/du · du/dx

Analogy: If you are a function, and your friend is a function, and I apply your friend first and then you, the effect is multiplied. The Chain Rule says: multiply the rates of change.
Example: Differentiate y = (3x² + 1)⁵.
Let u = 3x² + 1. dy/du = 5u⁴, du/dx = 6x.
dy/dx = 5(3x² + 1)⁴ · 6x = 30x(3x² + 1)⁴.

5.4 Derivatives of Special Functions

  • d/dx sin x = cos x
  • d/dx cos x = -sin x
  • d/dx tan x = sec² x
  • d/dx eˣ = eˣ
  • d/dx ln x = 1/x

5.5 Implicit Differentiation

Sometimes y is not written explicitly as a function of x. We differentiate both sides with respect to x, treating y as a function of x, and then solve for dy/dx.

Example: Find dy/dx for x² + y² = 25.
Differentiate: 2x + 2y(dy/dx) = 0 → dy/dx = -x/y.

5.6 Higher-Order Derivatives

We can differentiate a function multiple times to find higher-order derivatives. The second derivative, f''(x), tells us about concavity — whether the graph is curving upward or downward.

Example: If f(x) = x³ - 3x², then:
f'(x) = 3x² - 6x
f''(x) = 6x - 6
f'''(x) = 6

📘 Module 6: Applications of Derivatives

The Context: Why Derivatives Matter

Derivatives are not just abstract math — they tell us how things change. They help us find maximum profits, minimum costs, optimal paths, and much more.

6.1 Increasing and Decreasing Intervals

  • If f'(x) > 0, f is increasing (going up).
  • If f'(x) < 0, f is decreasing (going down).
Example: For f(x) = x³ - 3x, f'(x) = 3x² - 3 = 3(x-1)(x+1).
Increasing on (-∞, -1) and (1, ∞). Decreasing on (-1, 1).

6.2 Critical Points and Max/Min

  • Critical Points: Where f'(x) = 0 or undefined. These are candidates for local maxima/minima.
  • First Derivative Test: If f' changes from positive to negative at a critical point, it's a local maximum. If negative to positive, it's a local minimum.
  • Second Derivative Test: If f''(x) > 0, local minimum. If f''(x) < 0, local maximum.
Example: f(x) = x³ - 3x² - 9x + 5.
f'(x) = 3(x-3)(x+1). Critical points: x = -1, 3.
f''(x) = 6x - 6. At x = -1, f'' = -12 < 0 → local max. At x = 3, f'' = 12 > 0 → local min.

6.3 Optimization Problems

Optimization is finding the best value — the maximum profit, minimum cost, largest area, etc. The process:

  1. Set up the function to be optimized.
  2. Find its derivative.
  3. Set the derivative equal to zero and solve.
  4. Confirm it's a maximum or minimum (using the second derivative test).
Example: Find two positive numbers whose sum is 20 and whose product is maximum.
Let numbers be x and 20-x. Product P = x(20-x) = 20x - x².
P' = 20 - 2x = 0 → x = 10.
P'' = -2 < 0 → maximum. Numbers: 10 and 10.
