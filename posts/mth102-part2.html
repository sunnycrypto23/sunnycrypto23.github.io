📘 Module 3: Continuity

The Context: Why Continuity Matters

A function is continuous if you can draw its graph without lifting your pen from the paper. No breaks, no holes, no jumps. Why does this matter? Because continuous functions behave nicely — they have predictable outputs, and many important theorems (like the Intermediate Value Theorem) only apply to continuous functions.

Analogy: A continuous function is like a road with no potholes or gaps. You can drive smoothly from start to finish. A discontinuous function is like a road with a broken bridge — you can't get from one side to the other without stopping.

3.1 The Three Conditions for Continuity

A function f is continuous at x = a if all three of these conditions are met:

  1. f(a) is defined — the function exists at x = a.
  2. lim(x→a) f(x) exists — the left and right limits are equal.
  3. lim(x→a) f(x) = f(a) — the limit equals the function value.

If any of these conditions fails, the function is discontinuous at that point.

3.2 Types of Discontinuities

  • Removable Discontinuity (Hole): A single point is missing, but the function can be redefined to make it continuous. Example: f(x) = (x²-4)/(x-2) has a hole at x=2.
  • Jump Discontinuity (Step): The left and right limits exist but are different. Example: Piecewise functions with a sudden jump.
  • Infinite Discontinuity (Vertical Asymptote): The function grows without bound near a point. Example: f(x) = 1/(x-2) at x=2.

3.3 The Intermediate Value Theorem (IVT)

If f is continuous on the closed interval [a, b] and k is any number between f(a) and f(b), then there exists at least one number c in (a, b) such that f(c) = k.

Analogy: Imagine you're climbing a mountain. If you start at 1000 meters and end at 2000 meters, you must pass through every altitude between 1000 and 2000 meters at some point. You can't skip any height!
Example: Show that f(x) = x³ - x - 1 has a root between 1 and 2.
f(1) = 1 - 1 - 1 = -1 (negative).
f(2) = 8 - 2 - 1 = 5 (positive).
Since 0 is between -1 and 5, by IVT, there is a root c ∈ (1, 2).

📝 Module 3 Self-Assessment Test

Q1: Is f(x) = (x²-4)/(x-2) continuous at x=2? If not, how can it be redefined to make it continuous?
Q2: Find the value of k that makes f(x) = {x² + k, x ≤ 1; 2x + 3, x > 1} continuous at x=1.
Q3: Show that f(x) = x³ - x - 1 has a root between 1 and 2 using IVT.

✅ Full Solutions

A1: No. f(2) is undefined. Factor: (x-2)(x+2)/(x-2) = x+2. Redefine f(2) = 4 to make it continuous.

A2: Left limit: 1² + k = 1+k. Right limit: 2(1)+3 = 5. Set 1+k = 5 → k = 4.

A3: f(1) = -1 (negative), f(2) = 5 (positive). Since 0 is between -1 and 5, by IVT, there is a root c ∈ (1, 2).

📘 Module 4: Differentiation from First Principles

The Context: The Birth of the Derivative

We started with the Difference Quotient: (f(x+h) - f(x))/h. This is the slope of the secant line (a line through two points on the curve).

What if we bring those two points infinitely close? That's the derivative — the slope of the tangent line at a single point.

Analogy: Imagine you're driving a car. Your speedometer shows your instantaneous speed at any moment. This is like the derivative. The average speed over an entire trip is like the secant line slope.

4.1 The Definition of the Derivative

f'(x) = lim(h→0) (f(x+h) - f(x))/h

This is called differentiation from first principles.

4.2 Rules Derived from First Principles

  • Constant Rule: d/dx(c) = 0 (constants don't change).
  • Power Rule: d/dx(xⁿ) = nxⁿ⁻¹ (the exponent drops down and reduces by one).
  • Sum Rule: d/dx(f+g) = f' + g' (derivatives distribute over addition).
Example: Using first principles, find the derivative of f(x) = x².
f'(x) = lim(h→0) ((x+h)² - x²)/h = lim(h→0) (2xh + h²)/h = lim(h→0) (2x + h) = 2x.

📝 Module 4 Self-Assessment Test

Q1: Using first principles, find the derivative of f(x) = x².
Q2: Using first principles, find the derivative of f(x) = √x.
Q3: Differentiate f(x) = 5x⁴ - 3x² + 7 using the power rule.

✅ Full Solutions

A1: f'(x) = lim(h→0) ((x+h)² - x²)/h = lim(h→0) (2xh + h²)/h = 2x.

A2: f'(x) = lim(h→0) (√(x+h) - √x)/h. Rationalize the numerator: = lim(h→0) h/[h(√(x+h)+√x)] = 1/(2√x).

A3: f'(x) = 20x³ - 6x.
