📘 Module 7: Integration as Anti-differentiation

The Context: The Reverse Operation

If differentiation is about finding rates of change, integration is about finding the original function from its rate of change. It's like: if I know your speed at every moment, can I find out how far you've traveled?

Analogy: Differentiation is like breaking a puzzle into pieces. Integration is like putting the pieces back together. They are inverse operations — like addition and subtraction, or multiplication and division.

7.1 The Indefinite Integral

∫ f(x) dx = F(x) + C, where F'(x) = f(x).

The constant C is called the constant of integration — any constant can be added to the antiderivative.

7.2 The Power Rule for Integration

∫ xⁿ dx = xⁿ⁺¹/(n+1) + C, for n ≠ -1.

Example: ∫ x³ dx = x⁴/4 + C.

Special Case: ∫ x⁻¹ dx = ∫ 1/x dx = ln|x| + C.

7.3 Integration by Substitution (u-Substitution)

This is the reverse of the Chain Rule. Let u = g(x), then du = g'(x) dx.

Example: ∫ 2x/(x²+1) dx.
Let u = x²+1, du = 2x dx. Integral becomes ∫ 1/u du = ln|u| + C = ln(x²+1) + C.
Example: ∫ e³ˣ dx.
Let u = 3x, du = 3 dx → dx = du/3. Integral = ∫ eᵘ (du/3) = (1/3)eᵘ + C = (1/3)e³ˣ + C.

📝 Module 7 Self-Assessment Test

Q1: Evaluate ∫ (3x² + 4x - 1) dx.
Q2: Evaluate ∫ 2x/(x²+1) dx (u-substitution).
Q3: Evaluate ∫ e³ˣ dx.
Q4: Evaluate ∫ 1/x dx.

✅ Full Solutions

A1: x³ + 2x² - x + C.

A2: ln(x²+1) + C.

A3: (1/3)e³ˣ + C.

A4: ln|x| + C.

📘 Module 8: Advanced Integration Techniques

The Context: When Basic Integration Isn't Enough

Not all functions are simple polynomials. Some are products of functions, ratios of polynomials, or involve radicals. We need specialized techniques for these cases.

8.1 Integration by Parts

∫ u dv = uv - ∫ v du

Choose u as the function that simplifies when differentiated (LIATE rule: Logarithmic, Inverse trigonometric, Algebraic, Trigonometric, Exponential).

Example: ∫ x eˣ dx.
Let u = x, dv = eˣ dx → du = dx, v = eˣ.
∫ x eˣ dx = x eˣ - ∫ eˣ dx = x eˣ - eˣ + C.
Example: ∫ x cos(x) dx.
Let u = x, dv = cos x dx → du = dx, v = sin x.
∫ x cos x dx = x sin x - ∫ sin x dx = x sin x + cos x + C.

8.2 Partial Fractions

Decompose rational functions into simpler fractions for integration.

Example: ∫ 1/(x²-1) dx.
Decompose: 1/[(x-1)(x+1)] = 1/2/(x-1) - 1/2/(x+1).
Integral = (1/2) ln|x-1| - (1/2) ln|x+1| + C = (1/2) ln|(x-1)/(x+1)| + C.

8.3 Trigonometric Substitution

Use trigonometric identities to handle radicals like √(a² - x²).

Tip: For √(a² - x²), let x = a sin θ.

Example: ∫ √(1-x²) dx.
Let x = sin θ, dx = cos θ dθ. √(1-x²) = cos θ.
Integral becomes ∫ cos² θ dθ = ∫ (1+cos 2θ)/2 dθ = θ/2 + sin 2θ/4 + C = arcsin(x)/2 + x√(1-x²)/2 + C.

📝 Module 8 Self-Assessment Test

Q1: Evaluate ∫ x eˣ dx (Integration by Parts).
Q2: Evaluate ∫ 1/(x² - 1) dx (Partial Fractions).
Q3: Evaluate ∫ x cos(x) dx (Integration by Parts).

✅ Full Solutions

A1: x eˣ - eˣ + C.

A2: (1/2) ln|(x-1)/(x+1)| + C.

A3: x sin x + cos x + C.

📘 Module 9: The Fundamental Theorem of Calculus

The Context: The Grand Unification

Differentiation and integration are inverse operations. The Fundamental Theorem of Calculus (FTC) makes this relationship formal. It tells us that the net change of a function is equal to the integral of its rate of change.

Analogy: If you know your speed at every moment, you can find out how far you've traveled. That's what the FTC does — it connects rates of change (derivatives) to total change (integrals).

9.1 FTC Part 1

d/dx ∫ₐˣ f(t) dt = f(x)

Meaning: The derivative of an integral (with respect to the upper limit) is the original function.

Example: If F(x) = ∫₀ˣ √(t²+1) dt, find F'(2).
F'(x) = √(x²+1). F'(2) = √(4+1) = √5.

9.2 FTC Part 2

∫ₐᵇ f(x) dx = F(b) - F(a), where F is the antiderivative of f.

Meaning: To evaluate a definite integral, find the antiderivative and subtract the values at the endpoints.

Example: ∫₀² (x³ - x) dx.
Antiderivative: x⁴/4 - x²/2.
At 2: (16/4 - 4/2) = (4 - 2) = 2. At 0: 0.
Result: 2.

9.3 Area Under a Curve

∫ₐᵇ f(x) dx gives the signed area between the curve and the x-axis from x=a to x=b. If f(x) ≥ 0 on [a, b], it's the actual area.

Example: Area under f(x) = x² from x=1 to x=3.
∫₁³ x² dx = [x³/3]₁³ = 27/3 - 1/3 = 26/3.

9.4 Area Between Curves

Area between y = f(x) (top) and y = g(x) (bottom) from x=a to x=b:

Area = ∫ₐᵇ [f(x) - g(x)] dx

Example: Area between y = x and y = x².
Intersection points: x = 0, 1. Top is x, bottom is x².
Area = ∫₀¹ (x - x²) dx = [x²/2 - x³/3]₀¹ = 1/2 - 1/3 = 1/6.

📝 Module 9 Self-Assessment Test

Q1: Evaluate ∫₀² (x³ - x) dx.
Q2: Find the area under f(x) = x² from x=1 to x=3.
Q3: Find the area between the curves y = x and y = x².
Q4: If F(x) = ∫₀ˣ √(t²+1) dt, find F'(2).

✅ Full Solutions

A1: ∫₀² (x³ - x) dx = [x⁴/4 - x²/2]₀² = (16/4 - 4/2) - 0 = (4 - 2) = 2.

A2: ∫₁³ x² dx = [x³/3]₁³ = 27/3 - 1/3 = 26/3.

A3: ∫₀¹ (x - x²) dx = [x²/2 - x³/3]₀¹ = 1/2 - 1/3 = 1/6.

A4: By FTC Part 1, F'(x) = √(x²+1). F'(2) = √(4+1) = √5.
