📘 Module 1: Functions of Real Variables

The Context: Why We Start Here

Before we can study change (which is what calculus is all about), we must first understand the things that change. A function is simply a rule that takes an input and produces an output. In computer science, functions are the building blocks of programming — methods, procedures, and lambda calculus. In physics, they model motion, forces, and energy. In economics, they model cost, profit, and demand.

Analogy: A function is like a vending machine. You press a button (input), and the machine gives you exactly one snack (output). If you press the same button and sometimes get chips, sometimes nothing, the machine is "not a function."

1.1 The Core Definition

A function f from set X (the Domain) to set Y (the Codomain) assigns exactly one element f(x) ∈ Y to every element x ∈ X.

  • Domain: All possible inputs that are "allowed." For example, you cannot put a negative number inside a square root (if we're working with real numbers).
  • Codomain: The entire set Y that the function could output.
  • Range: The actual outputs that the function does produce. The range is always a subset of the codomain.
Example: f(x) = x²
Domain: All real numbers (ℝ)
Codomain: All real numbers (ℝ)
Range: All non-negative real numbers [0, ∞) — because x² is never negative.

1.2 Types of Functions (The "Species")

  • Polynomial: f(x) = aₙxⁿ + ... + a₀ (e.g., linear, quadratic, cubic). These are smooth, continuous curves.
  • Rational: f(x) = P(x)/Q(x). Watch out for Q(x) = 0 — these create vertical asymptotes (barriers the graph cannot cross).
  • Radical: Involves roots (e.g., √x). The domain is restricted: whatever is under the root must be ≥ 0 (for even roots).
  • Transcendental: Trigonometric (sin x, cos x), Exponential (eˣ), Logarithmic (ln x). These are essential for modeling waves, population growth, and decay.

1.3 Even, Odd, and Periodic Functions (Symmetry)

  • Even: f(-x) = f(x). The graph mirrors perfectly over the Y-axis (like x²). Why it matters: Saves computation — you only need to calculate half the graph.
  • Odd: f(-x) = -f(x). The graph has 180° rotational symmetry about the origin (like x³).
  • Periodic: f(x + T) = f(x). The graph repeats every interval T (like sin x, period 2π). Crucial for computer science: Digital signal processing, audio waves, and graphics lighting all rely on periodic functions.

1.4 Composite Functions (Function of a Function)

This is (f ∘ g)(x) = f(g(x)). You evaluate the inner function first, then feed that result into the outer function.

Critical Domain Rule: x must be in the domain of g, AND g(x) must be in the domain of f. This is a common trap in exams.
Example: f(x) = 1/x and g(x) = √(x-2).
(f ∘ g)(x) = 1/√(x-2).
Domain: x > 2 (because √(x-2) must be defined AND not equal to zero).

1.5 The Difference Quotient (The Precursor to Derivatives)

This is the formula: (f(x+h) - f(x))/h

Geometrically, it represents the slope of a secant line (a line cutting through two points on a curve). Historically, Newton and Leibniz stared at this formula and asked: "What happens as h gets infinitely close to zero?" That question is the birth of calculus.

📝 Module 1 Self-Assessment Test

Q1 (Domain & Range): Find the domain and range of f(x) = 3x/(x² - 4).
Q2 (Even/Odd): Determine if f(x) = x³ sin(x) is even, odd, or neither.
Q3 (Composite): Given f(x) = 1/x and g(x) = √(x-2), find (f ∘ g)(x) and its domain.
Q4 (Periodicity): What is the fundamental period of f(x) = cos(4x)?
Q5 (Difference Quotient): Compute (f(x+h)-f(x))/h for f(x) = 2x² - 3x. Simplify.

✅ Full Solutions

A1: Domain: x ≠ ±2. Range: ℝ (the function can produce any real number).

A2: f(-x) = (-x)³ sin(-x) = (-x³)(-sin x) = x³ sin x = f(x). Even.

A3: (f ∘ g)(x) = 1/√(x-2). Domain: x > 2.

A4: T = 2π/4 = π/2.

A5: f(x+h) = 2x²+4xh+2h²-3x-3h. Subtract f(x): 4xh+2h²-3h. Divide by h: 4x + 2h - 3.

📘 Module 2: Limits & Limit Theorems

The Context: Why Limits?

Before calculus, mathematicians could calculate the slope of a straight line (rise over run). But they couldn't calculate the slope of a curve at a single point. Why? Because a curve changes direction constantly — how do you find the slope at one exact point?

The solution came from ancient Greece (Zeno's paradoxes) and was fully developed by Newton and Leibniz in the 1600s. Their insight: "What if we take two points on the curve, bring them closer and closer together, and see what the slope approaches?"

That "approaches" is the key. The limit is the intended value as we get infinitely close — even if we never actually reach it.

Analogy: Imagine walking toward a wall. You get closer and closer — 1 meter, 0.1 meters, 0.01 meters. You never actually touch the wall, but you can predict exactly where you'll end up. That prediction is the limit.

2.1 The Intuition of Limits

Consider f(x) = (x² - 9)/(x - 3). At x = 3, the function is undefined (0/0). But what happens as x gets close to 3?

  • x = 2.9 → (8.41 - 9)/(2.9 - 3) = (-0.59)/(-0.1) = 5.9
  • x = 2.99 → (8.9401 - 9)/(2.99 - 3) = (-0.0599)/(-0.01) = 5.99
  • x = 2.999 → (8.994001 - 9)/(2.999 - 3) = (-0.005999)/(-0.001) = 5.999

It's getting closer and closer to 6. That's the limit!

2.2 Limit Theorems

  • Constant Rule: lim(x→a) c = c
  • Sum Rule: lim(x→a) [f(x) + g(x)] = lim f(x) + lim g(x)
  • Product Rule: lim(x→a) [f(x) · g(x)] = lim f(x) · lim g(x)
  • Quotient Rule: lim(x→a) [f(x)/g(x)] = lim f(x) / lim g(x), provided lim g(x) ≠ 0
  • Power Rule: lim(x→a) [f(x)]ⁿ = [lim f(x)]ⁿ
  • Root Rule: lim(x→a) ⁿ√f(x) = ⁿ√(lim f(x)), provided the root is defined

2.3 The Squeeze Theorem

If g(x) ≤ f(x) ≤ h(x) and lim(x→a) g(x) = lim(x→a) h(x) = L, then lim(x→a) f(x) = L.

Analogy: Imagine you're standing between two friends who are walking toward the same spot. If they end up at the same place, you must be there too!
Example: If 1 - x²/2 ≤ f(x) ≤ 1 + x²/2, find lim(x→0) f(x).
Both bounds approach 1, so f(x) must also approach 1.

2.4 Infinite Limits and Limits at Infinity

  • Infinite Limit: lim(x→a) 1/(x-a)² = +∞ (the function grows without bound).
  • Limit at Infinity: lim(x→∞) (3x² + 2x)/(5x² - 4) = 3/5 (divide by the highest power of x).

2.5 Indeterminate Forms

Forms like 0/0, ∞/∞, 0·∞, ∞ - ∞, 1^∞, 0^0, and ∞^0 are called indeterminate because they don't give a clear answer. We resolve them using algebraic manipulation (factoring, rationalizing) or more advanced techniques like L'Hôpital's Rule (which comes later).

📝 Module 2 Self-Assessment Test

Q1: Evaluate lim(x→3) (x² - 9)/(x - 3). Show your algebraic manipulation.
Q2: Evaluate lim(x→∞) (3x² + 2x)/(5x² - 4). Explain how you handled infinity.
Q3: Using the Squeeze Theorem, if 1 - x²/2 ≤ f(x) ≤ 1 + x²/2, find lim(x→0) f(x). Explain why the theorem applies.
Q4: Evaluate lim(x→0) sin(2x)/x. Show your reasoning.
Q5: Consider f(x) = 1/(x - 2). What happens as x approaches 2 from the left (x→2⁻) and from the right (x→2⁺)? Does the two-sided limit exist? Explain.

✅ Full Solutions

A1: Factor: (x-3)(x+3)/(x-3) = x+3. Limit = 3+3 = 6.

A2: Divide numerator and denominator by x²: (3 + 2/x)/(5 - 4/x²) → (3 + 0)/(5 - 0) = 3/5.

A3: lim(1 - x²/2) = 1, lim(1 + x²/2) = 1. Both bounds approach 1, so f(x) → 1.

A4: Let u = 2x. Then lim(x→0) sin(2x)/x = lim(u→0) sin(u)/(u/2) = 2·lim(u→0) sin(u)/u = 2·1 = 2.

A5: As x→2⁻, x-2 is negative and very small → f(x) → -∞. As x→2⁺, x-2 is positive and very small → f(x) → +∞. Since the left and right limits are different, the two-sided limit does not exist.
